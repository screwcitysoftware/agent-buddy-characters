Installation

Add a pack in a minute

  1. Download the character’s .acpk file.
  2. Open Agent Buddy Settings and select Characters.
  3. Select Add character pack, choose the file, and then select Install.

These are independent add-on packs. Agent Buddy retains its own copy after import.
